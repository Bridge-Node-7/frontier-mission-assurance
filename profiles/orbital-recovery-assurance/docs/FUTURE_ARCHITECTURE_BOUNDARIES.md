# Future Architecture Boundaries

Research around orbital recovery suggests several useful future capabilities. They should not all be implemented inside this FMA profile.

## Keep as cross-BN7 doctrine

- **Epistemic Firewall** — inference cannot promote itself into evidence.
- **Evidence independence** — corroboration must account for shared provenance roots.
- **Robust Action Envelope** — optimize only inside the declared safe option set.
- **Time to Trust** — distinguish restored function from restored evidence-backed capability.

## Candidate Mission Graph capabilities

- common-mode dependency detection across supposedly redundant recovery paths;
- recovery-option reserve / activatability relationships;
- graph-level proof requests for unresolved dependencies.

Mission Graph should connect these relationships without becoming the evidence warehouse.

## Candidate private mission-assurance capabilities

- independent witness / shadow-state reconstruction;
- known-good configuration and recovery-state escrow;
- richer telemetry lineage tied to local trust infrastructure.

These may contain sensitive operational state and therefore do not belong in the public profile by default.

## Candidate future portable contracts

- assurance metadata accompanying high-consequence command requests;
- provenance-rich telemetry envelopes;
- machine-readable local evidence-admissibility policies.

These require real domain validation before becoming FMA contracts. They must not give FMA command authority.

## Candidate institutional primitive

An Assurance Compiler could eventually translate architecture, claims, policies, dependencies, and recovery objectives into proof obligations, evidence requirements, tests, and reopen conditions.

It should be promoted only after repeated cross-domain proof demonstrates that the same abstraction survives beyond a single profile.

## Explicit non-goal

Do **not** create a monolithic "Mission Epistemic OS" repository. The useful idea is an epistemic assurance plane expressed through existing BN7 ownership boundaries, not a new system that duplicates Intelligence Library, Mission Graph, FMA, FDE, or domain systems.
