# Hindcast Protocol

Historical cases are useful for regression testing only when hindsight is controlled.

For each off-repository real case:

1. set an evidence cutoff before the known outcome;
2. map source identity to sanitized internal references before any GitHub artifact is produced;
3. preregister the target probability, decision objective, baseline, and scoring rule;
4. run the model using only information available at the cutoff;
5. reveal the outcome after the prediction artifact is finalized;
6. score probability and decision regret;
7. preserve failures and contradictions.

A few heterogeneous cases may demonstrate representational breadth; they do not establish
probability calibration. Calibration requires sufficiently large, class-appropriate,
representative cohorts.

Public GitHub fixtures remain synthetic.
