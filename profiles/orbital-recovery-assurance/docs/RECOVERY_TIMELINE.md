# Recovery Timeline Metrics

Technical recovery is not the same as trustworthy recovery.

The reference timeline recognizes:

- **TTC** — time from anomaly recognition to containment;
- **TTE** — time to establish the evidence required for the next recovery stage;
- **TTMC** — time to minimum credible capability;
- **TTT** — time to re-establish the evidence required to trust a defined capability;
- **TTV** — time to verify the recovered configuration against its declared requirements.

These are descriptive elapsed-time measures. They are not universal performance targets.
