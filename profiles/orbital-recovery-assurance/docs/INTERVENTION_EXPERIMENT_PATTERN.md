# Intervention Experiment Pattern

A recovery intervention should be admitted only through a mission-derived evidence chain:

`Mission capability → requirement → intervention hypothesis → experiment → evidence → requalification`

For an external communications-aperture reuse experiment, the sequence is:

1. define the required communications service and link margin;
2. derive antenna performance requirements from the link need;
3. characterize geometry and surface condition;
4. build a measured electromagnetic representation appropriate to the experiment;
5. position and calibrate an independent feed architecture;
6. sweep geometric and RF uncertainties;
7. measure realized performance against mission-derived acceptance criteria;
8. preserve limitations and failure modes;
9. admit the intervention into a recovery option set only when the evidence supports it.

No universal percentage-of-theoretical-gain threshold is assumed. Acceptance comes from
the intended mission requirement.
