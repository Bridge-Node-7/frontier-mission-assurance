# Use and Evaluation

Frontier Mission Assurance is publicly visible so technical reviewers can inspect its contracts, reference implementation, source-neutral examples, validation behavior, and release evidence.

The public repository does not by itself grant operational-use rights.

## Public evaluation

The rights for the public release are defined by [`../LICENSE`](../LICENSE). The current public posture is **evaluation and review only**.

A public evaluator can inspect the repository and assess the reference behavior under those terms. Nothing in this document changes or expands the license.

## Use beyond public evaluation

Internal operational use, private deployment, integration into governed workflows, modification of adapters or other derivative work, redistribution, resale, and other rights not granted by the public license require separate written permission or agreement from Bridge Node 7.

For current engagement information, visit [Bridge Node 7](https://bridgenode7.com/).

## Governed one-decision evaluation

A practical first governed engagement should remain small.

Start with:

```text
one consequential decision
one frozen system or research revision
1–3 controlling claims or requirements
only the critical assumptions
only the decision-relevant evidence references
one or two required expert gates
one explicit reopen contract
```

The purpose is to determine whether FMA improves the decision—not to model the organization.

A bounded evaluation can produce:

- an inspectable decision basis;
- visible assumptions and evidence gaps;
- references to authoritative evidence without relocating protected source material;
- a reproducibility record where appropriate;
- dependency/change-impact visibility;
- explicit conditions that reopen the decision.

## Evidence handling

Use the public reference with synthetic, public-source, or otherwise
approved-for-release material.

For operational evaluations, keep authoritative evidence in the systems
designated to hold it and carry only the bounded references or projections
needed for review. FMA is not a replacement system of record for the underlying
evidence.

## Decision authority

FMA can organize evidence, validate declared contracts, surface gaps, and identify affected basis when a dependency changes.

Qualified domain experts and accountable authorities retain scientific, engineering, safety, security, legal, regulatory, acquisition, program, investment, and other consequential judgments.

## Pilot success measures

A useful evaluation measures whether reviewers improve on outcomes such as:

- decision-basis reconstruction time;
- hidden-assumption discovery;
- evidence-gap discovery;
- time to identify impact after a changed dependency;
- repeated requests for already-known provenance or rationale.

The system earns broader adoption only when it improves real review work.
